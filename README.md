## Featured Project — MiniChat

A full-stack real-time group chat app: HTML/CSS/JS frontend, Node.js + Express backend, Socket.io for live messaging, MongoDB Atlas for persistence.

- Room-based real-time chat with Socket.io
- JWT authentication with refresh tokens
- Security middleware: Helmet, rate limiting, input sanitization

**Repo:** [github.com/anurag-yadav10/MiniChat](https://github.com/anurag-yadav10/MiniChat)
